# ربات اخبار فولاد (رایگان، روی GitHub Actions)

## چیدمان فایل‌ها
```
steel-news-bot/
├── steel_news_bot.py         # اسکریپت اصلی
├── requirements.txt          # کتابخانه‌های موردنیاز
├── sent_links.json           # (خودش ساخته می‌شه) تاریخچه‌ی اخبار ارسال‌شده
└── .github/workflows/steel-news.yml   # زمان‌بند رایگان GitHub
```

## قدم‌ها

1. **ساخت بات تلگرام** با `@BotFather` و گرفتن Token.
2. **پیدا کردن Chat ID** با باز کردن:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   بعد از اینکه یک بار به بات پیام دادید.
3. **ویرایش `steel_news_bot.py`**: لینک‌های RSS دلخواه‌تون رو داخل لیست
   `RSS_FEEDS` بذارید (هر تعداد که خواستید).
3.۵. **گرفتن کلید رایگان Gemini** (برای خلاصه‌سازی و نتیجه‌گیری خودکار):
   - برید به `aistudio.google.com/app/apikey`
   - با اکانت گوگل وارد بشید و `Create API Key` بزنید
   - این کلید رو هم مثل بقیه، به‌عنوان Secret اضافه می‌کنید (قدم ۵)
   - اگه این کلید رو تنظیم نکنید، ربات به‌جای خلاصه، همون فرمت قبلی
     (تیتر + لینک) رو می‌فرسته — یعنی این بخش کاملاً اختیاریه.
4. **ساخت ریپازیتوری روی GitHub** (می‌تونه Private باشه) و آپلود همین پوشه.
5. توی تنظیمات ریپو برید به:
   `Settings → Secrets and variables → Actions → New repository secret`
   و مقادیر زیر رو اضافه کنید:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `GEMINI_API_KEY` (اختیاری — برای فعال‌شدن خلاصه‌سازی و جمع‌بندی)
6. برید تب **Actions** و workflow رو یک بار دستی اجرا کنید
   (`Run workflow`) تا مطمئن بشید درست کار می‌کنه.
7. از این به بعد GitHub Actions به‌صورت خودکار هر ۲ ساعت
   (قابل تغییر توی فایل `steel-news.yml`، خط `cron`) اجرا می‌شه و
   اخبار جدید رو به تلگرام‌تون می‌فرسته — کاملاً رایگان
   (تا ۲۰۰۰ دقیقه در ماه برای ریپوی خصوصی، و نامحدود برای ریپوی عمومی).

## نکات
- برای اجرای محلی و تست، می‌تونید همین‌طوری اجراش کنید:
  ```
  pip install -r requirements.txt
  export TELEGRAM_BOT_TOKEN="..."
  export TELEGRAM_CHAT_ID="..."
  python steel_news_bot.py
  ```
- اگه می‌خواید فیلتر کلیدواژه نداشته باشید و همه‌چیز فید رو بفرسته،
  لیست `KEYWORDS` رو خالی (`[]`) بذارید.
- اگه یه فید RSS پیدا نکردید، دنبال آیکون RSS پایین سایت خبری بگردید،
  یا آدرس `سایت.com/feed` و `سایت.com/rss` رو امتحان کنید.
